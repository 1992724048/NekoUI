关于 NekoUI HCT 颜色工具

            
这是一个基于 Material You HCT 色彩引擎的交互式取色与配色调试工具。从单个 seed 颜色出发，生成 6 组色调色板与 47 个 ColorScheme 角色，并可在真实界面中预览配色效果。

            
JS 端色彩引擎与 ColorScheme.cpp 同源实现，逐字段对齐 material_color_utilities 0.13.0。

            
功能特性

            
    
                
  • seed 选取：取色器 / 十六进制输入 / 常用颜色 / 随机种子
    • 
                
  • 色调色带：primary · secondary · tertiary · neutral · neutralVariant · error（tone 5–95）
    • 
                
  • 角色表格：47 个 ColorScheme 角色，hover 显示五色值
    • 
                
  • 主题切换：亮 / 暗主题，页面配色随 seed 联动
    • 
                
  • 右键菜单：复制任意格式色值（Hex / RGB / HSL / HSV / CMYK / VEC4）
    • 
                
  • 17 语言导出：C++ / JSON / CSS / Python / JavaScript 等
    • 
                
  • 控件配色参考：23 个 MD3 风格控件，可交互体验
    • 
                
  • 页面预览：通用设置界面，实时预览配色效果
    • 
            

            
使用说明

            
    
                
  1. 在「取色工具」页选择一个 seed 颜色
    2. 
                
  2. 观察色带与角色表的联动刷新
    3. 
                
  3. 在「控件配色」页体验控件交互状态
    4. 
                
  4. 在「页面预览」页查看界面整体效果
    5. 
            

            
快速上手

            
在开发者控制台直接调用引擎 API：

            
const scheme = NekoHCT.scheme('#6750a4', 'light');
console.log(scheme.primary);            // 主色
console.log(scheme.onPrimary);          // 主色上的文字
console.log(scheme.primary_container);  // 主色容器背景

            
技术说明

            
    
                
  • 色彩管线：sRGB → XYZ → CAM16 → HCT，含临界平面色相二分回退
    • 
                
  • 零外部依赖，file:// 直接打开即用
    • 
                
  • 页面配色全部由当前 seed 的 scheme() 派生，随主题联动
    •
