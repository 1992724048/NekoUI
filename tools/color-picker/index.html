关于项目

            
NekoUI HCT 颜色工具是 NekoUI 开源项目附带的交互式取色与配色调试工具，基于 Material You HCT 色彩引擎。

            

                

                    
                    
                    
                    
                

                

                    NekoUI HCT 颜色工具
                    
NekoUI 是一个使用 DirectX 11 渲染的 Windows C++ GUI 框架；本工具是其 ColorScheme（HCT 色彩引擎）的可视化调试入口——从单一 seed 生成 6 组色调色板与 47 个配色角色。

功能特性

            

                
01seed 选取
取色器 / 十六进制输入 / 常用颜色 / 随机种子

                
02色调色带
primary · secondary · tertiary · neutral · neutralVariant · error（tone 5–95）

                
03角色表格
47 个 ColorScheme 角色，hover 显示 RGB / HSL / HSV / CMYK / VEC4 五色值

                
04主题切换
亮 / 暗主题联动，页面配色随 seed 实时刷新

                
05右键菜单
按格式复制色值（Hex / RGB / HSL / HSV / CMYK / VEC4）

                
0617 语言导出
C++ / JSON / CSS / Python / JavaScript 等角色字典

                
07控件配色参考
23 个 MD3 风格控件，可交互体验

                
08页面预览
通用设置界面，实时预览界面配色效果

                
09开箱即用
无需构建、无需服务器，浏览器直接打开即可使用

            

            
使用说明

            

                

                    1
                    
选择 seed 颜色
打开「取色工具」页，选取一个种子颜色

                

                

                    2
                    
查看联动刷新
观察 6 组色调色带与 47 角色表的变化

                

                

                    3
                    
切换主题
亮 / 暗主题，对比两种配色方案

                

                

                    4
                    
复制色值
右键任意色块，按所需格式复制

                

                

                    5
                    
整体预览
在「控件配色」与「页面预览」页查看效果

                

                

                    6
                    
导出字典
在导出面板选择语言，生成角色字典代码
